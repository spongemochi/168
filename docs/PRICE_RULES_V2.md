# 自动价格裁决 v2

适用于更新后新封存且明确包含 `claim.ruleVersion=168-price-usd-v2` 的普通 BTC/USD、ETH/USD 价格承诺。已有 v1 密文和规则保持原样；事件继续人工裁决。计分 v6 已启用并有首笔主网结算，详见 [计分规则](SCORING_V2.md)。

## 事前固定的口径

时间 T、标的、严格高于/低于方向和阈值写入原始密文。三种固定价格为 T 前最后一个安全/最终区块上的 Chainlink BNB、Chainlink Base，以及截至 T 已完成的 OKX 美元指数一分钟蜡烛。Chainlink 最多允许早于 T 一小时，不能使用 T 之后的更新。沿用 v1 的历史区块边界证明。

- 三源齐备：取中位数，严格比较；等于阈值记未中。
- 两源齐备：必须有 OKX 和一路 Chainlink。BNB、Base 的两路 Chainlink 不算两个不同数据提供方。
- 两源差价 `(高价−低价)/低价` 必须不超过 2%，并分别对阈值得出同一结论；满足后发布共同的命中/未中结论，展示两源均价。
- 单源、两源差价过大、两源结论相反：保留待证据状态并重试，判官可审核公开证据。不把取价故障判成未中。
- 不认识的版本不自动裁决；没有版本的旧承诺仍进入规则审核，不补写新版本。

所有比较用整数定点数，避免浮点数边界误差。当前计分版本固定使用 v2 价格规则，普通判断与背书计分分别验收。

## RPC 读取策略与价格来源是不同层次

新增独立的价格 RPC 客户端：至少两个独立运营方一致回答同一历史区块的读取；只要收到不同有效回答就拒绝，同一家多网址仍只算一票。安全/最终区块要求至少两个独立运营方回答并取最低高度，再用严格一致的历史区块头查出 T 的边界。每次采集核对链号。

它只用于 BNB 和 Base 的预言机。X Layer 身份、原消息、揭示、裁决收录、nonce 和费用预算保持原实现。v1 仍必须集齐三种价格来源；放宽 RPC 访问门槛不会把两种价格源当成三种。

## 当前验收

现有 Worker 为 `168-scoring-v6`，包含 v1/v2 价格路径与计分。v2 普通判断以及首笔 v2 背书计分判断均已有主网验收，见 [公开凭证](../verification/README.md)。旧自动揭示修复包仅作历史归档。

后台部署不会更新链上网站。实际验收要求揭示与裁决消息在安全区块中通过核验；广播、本机算价或仅看到交易回执不能代替验收。读取失败应按原规则重试，不修改原承诺版本。
